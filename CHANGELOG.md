# Changelog

## 1.0.0 (2026-03-04) - Formal Release
- **Full i18n Support**: Integrated English and Traditional Chinese translations across all blocks, tooltips, and categories.
- **Dynamic Help System**: Multilingual documentation linkage for all major blocks.
- **Visuals Overhaul**: Added comprehensive Geometry (Rect, Ellipse, Triangle, Line) and Transform (Push/Pop, Scale, Rotate) blocks.
- **Audio Performance Enhancements**: New rhythm phrase arrangement, custom chord definitions, and Count-in metronome support.
- **Hardware Interaction**: Thread-safe Serial communication and improved MIDI device bus management.
- **UI/UX Polishing**: Fixed Dirty State management, serial data multi-line layouts, and category icon consistency.
